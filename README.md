# RowPilot（ローパイロット）- ボート競技（ローイング）のための統合トレーニング・艤装管理アプリ

## 1. 概要 (Overview)
**RowPilot** は、iOS向けに構築されたボート競技（ローイング）の選手、コーチ、マネージャーのためのプレミアムなオールインワン・アプリケーションです。

単なるGPS計測アプリにとどまらず、ボート上での高精度な水上計測、Concept2製エルゴメーター（PM5）との複数台同時連携によるチームトレーニング監視（マネージャー機能）、極めて詳細なボートの艤装（リギング）データの記録・ビジュアル化、水上での安全を考慮した緊急SOSやGPS連動の潮汐データ連携など、**ローイングに必要なすべての機能を洗練された美しいデザインで一つに統合した究極のツール**です。

---

## 2. 対象ユーザー
*   **ローイング選手 (Rower)**: シングルスカルからエイトまで、日々の水上・陸上トレーニング（エルゴ）を記録・分析し、漕ぎの効率を最大化したい選手。
*   **コーチ・マネージャー (Coach / Manager)**: 大学のボート部、実業団、クラブチームなどで、複数人のエルゴデータを同時にリアルタイム監視・記録・指導したい指導者。
*   **ボートセッター (Boat Technician / Rigger)**: 艇とオールのセッティングをミリメートル単位で記録し、艇のパフォーマンスを極限まで引き出したい選手や艤装担当者。

---

## 3. コア機能の詳細

### ① 水上トレーニングを支援する「ローイング計測」
スマートフォンを艇にマウントするだけで、過酷な水上環境でも正確なデータを取得・提供します。
*   **高精度SPM（ストロークレート）自動算出**: スマートフォン内蔵の加速度センサーをリアルタイム解析し、直近2〜3ストロークの平均値から1分間あたりのストローク数（SPM）を自動で算出。
*   **GPSトラッキング**: 距離、速度、500mスプリットタイム、移動経路を精密に記録。
*   **スマート音声フィードバック**: 
    *   水上では画面の確認が難しいため、一定時間・距離ごとに経過時間、距離、SPM、速度を自動で音声読み上げ。
    *   目標とするSPMを設定しておけば、ペースの乖離に対して「良いペースです」「もう少しペースを上げましょう」といった音声アドバイスをリアルタイムでフィードバック。
*   **縦横画面UIの最適化**: 艇へのスマートフォンのマウント位置や向き（縦・横）に応じて、見やすいようにUIレイアウトが自動的に切り替わります。
*   **水上の安全（緊急SOS機能）**: 転覆や怪我などの緊急時に、ユーザーの現在地をGoogle MapsやApple Mapsのリンク付きで、あらかじめ登録した緊急連絡先へ瞬時に送信できるSOSアシスト機能を搭載。

### ② コーチ・指導者のための「マネージャーモード」
陸上トレーニングの主役であるConcept2製ローイングエルゴメーターのモニター「PM5」とBluetoothで複数台同時に接続し、指導者が一括管理できる業界初の非常に強力な機能です。
*   **複数台同時リアルタイム監視**: 複数台のPM5モニターから送信される、選手それぞれの現在のペース、出力（ワット）、距離、経過時間、SPMを一画面でリアルタイムにモニタリング可能。グリッドのレイアウト数やカードサイズも調整可能。
*   **ワークアウト一斉設定送信**: 目標距離や目標時間、インターバル、レスト時間などのメニューを、マネージャーのアプリから接続中のすべてのPM5モニターへ一括で送信し、リセットとメニューの開始を制御可能。選手が個々にモニターを設定する手間を省き、チーム全体の同期トレーニングを実現。
*   **レースビュー (Race View) - *MAXプラン限定***: 単一距離のワークアウト中、横画面に切り替えることで選手たちの現在位置をビジュアル化したレースコースとして表示。誰が今リードしているか、タイム差がどれくらいあるかをリアルタイムでグラフィカルに可視化し、競争心を刺激します。
*   **一括保存と自動共有**: トレーニング終了後、全選手の記録を一括で保存し、自動的な共有フロー（データのCSVエクスポートや選手への共有など）を開始できます。

### ③ ボートを最適化する「リギング（艤装）管理エディタ」
ボートのパフォーマンスを左右する艤装（リギング）の数値をデジタル化し、視覚的に管理できます。
*   **ミリ単位の詳細な設定パラメータ**:
    *   *オール (Oar)*: タイプ（Scull/Sweep）、全長、インボード、アウトボード（自動計算）、ブレードタイプ、スリーブのピッチ角、グリップ径。
    *   *ボート (Boat)*: スパン/スプレッド（ピン間隔）、ワークハイト（シートからオールロックまでの高さ）、ピッチ角（後傾角）、ラテラルピッチ（左右傾斜ブッシュの設定）、フットストレッチ位置、フットプレート角度・高さ、シート位置。
*   **美しいビジュアル図面 (Diagram View)**: SwiftUIで描画された精密なボート、オール、オールロックのベクター図面が、入力された数値に応じて動的にスケールや角度を変化。現在のセッティングを視覚的・直感的に理解することができます。

### ④ 水上の環境を把握する「潮汐（タイド）＆天気連携」
自然環境と調和するローイングならではの、水上環境把握をサポートします。
*   **気象庁公式データとのGPS自動連携**: GPSで取得した現在地から日本国内全国239地点の最寄りの潮汐観測所を自動特定し、最新の潮汐データを自動で取得。
*   **美しい潮汐グラフ**: 24時間の潮位変化を滑らかな曲線グラフで表示。現在時刻のラインも重ねて表示されるため、潮の流れがどう変化するか一目でわかります。干潮・満潮の時間と潮位もひと目で確認可能です。
*   **天気・風向の取得**: ボート競技において極めて重要な風向や風速などの気象情報も合わせて確認できます。

### ⑤ エルゴメーター（PM5）個人連携とフォースカーブ
エルゴを漕ぐ選手自身が自分のストロークの質を向上させるための機能です。
*   **フォースカーブ (Force Curve) の可視化**: 1ストローク中にどのように力を加えているかの曲線（フォースカーブ）を表示。キャッチからフィニッシュまでの力の伝え方の癖を分析し、より効率的な漕ぎ方を追求できます。

## 4. 技術的・デザイン的特長
*   **洗練されたダークモードとガラスモルフィズム**: 暗い水上や屋内エルゴ場でも高い視認性を誇る、HSLベースのカラーリングと半透明マテリアル（Glassmorphism）を多用したプレミアムなUIデザイン。
*   **ネイティブAPIのフル活用**: iOSの CoreBluetooth（PM5との無線接続）、CoreLocation（GPSトラッキング）、CoreMotion（センサー値）、AVSpeech（音声アシスト）、Swift Charts（潮汐・グラフ可視化）など、AppleのネイティブAPIを余すことなく使い切った高い安定性とパフォーマンス。
*   **CoreDataによる強固なデータ永続化**: すべての記録や艤装設定はオフラインでも安全に保存され、後から振り返りや分析が可能です。

---
## 5. 強固な安全性
RowPilotはサーバーを持たず、高校生の個人開発者のもと運営されています。  
位置情報などのセキュアな情報が運営側に送信されることは決してなく、計測データを共有する時も自分で判断できるので安全です。
